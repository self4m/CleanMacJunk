# CleanMacJunk
一款用于**批量清理 Mac 遗留垃圾元数据**的轻量工具，防止跨设备文件污染。

## 项目介绍
日常将文件从 Mac 拷贝至 U 盘、移动硬盘等外部存储设备时，系统会静默自动生成大量隐藏元数据文件。  
这类文件仅为 macOS 系统服务，**在 Windows / 跨平台场景完全无用**，不仅占用存储空间、打乱目录结构，还会污染 Git 仓库、干扰文件同步、影响目录整洁度。  
本工具会根据垃圾文件特征**定向清理**，无需人工判断，安全无残留。

## 清理范围
Mac 系统生成的冗余垃圾文件：
- `.DS_Store` 目录视图、图标布局缓存文件
- `.fseventsd` 文件系统监控日志目录
- `.Spotlight-V100` 聚焦搜索索引缓存目录
- `.TemporaryItems` 系统临时缓存目录
- `.Trashes` 外置设备回收站残留目录
- `._*` Mac 资源分支、拓展属性附属文件

## 解决痛点
1. 跨设备拷贝后散落大量隐藏文件，目录杂乱臃肿 
2. 无效文件占用外置存储、移动设备空间 
3. 极易被 Git 误提交，造成仓库体积膨胀、历史污染 
4. 干扰文件同步、打包分发、归档整理等操作 
5. 破坏目录整洁，强迫症刚需清理

## 使用
由于删除的元数据是 macOS 系统自身使用的文件，**强烈建议仅在 Windows 系统上使用**  
1. 在[releases](https://github.com/self4m/CleanMacJunk/releases)中下载编译好的程序  
2. 将工具放在**外部存储设备的根目录中**
3. 双击运行，工具会自动清理当前目录 + 所有子目录中的 Mac 垃圾

## 构建
### Windows 命令行构建（本机编译）
安装 Go 环境后，克隆本项目并在项目根目录执行构建命令：
```bash
go build -o CleanMacJunk.exe
```
### 跨平台命令行构建（macOS / Linux 等系统）
安装 Go 环境后，克隆本项目并在项目根目录执行交叉编译构建命令：
```bash
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -o CleanMacJunk.exe
```
### Goland构建
安装 GoLand 并配置好 Go 开发环境，打开项目后，点击右上角运行按钮即可自动编译构建。
